[Normal] 1. Project Overview
[Normal] This document represents a premium, end-to-end development proposal for a custom-built Gold Jewellery Android Application, developed as a one-to-one functional and visual clone of an existing reference application, namely “Rajendra Gold”.
[Normal] The objective of this project is to replicate the core structure, user flow, and business logic of the reference application while implementing the client-specific requirements outlined in this document. The development will focus on accuracy, stability, and controlled enhancements, rather than experimental or unproven features.
[Normal] The application is engineered with a secure, scalable, and role-driven architecture, ensuring performance, reliability, and long-term maintainability. While the reference app is used for functional alignment, the codebase, authentication logic, and backend handling will be entirely rebuilt from scratch.
[Normal] The scope includes requirement engineering, UI/UX replication and refinement, backend logic implementation, security controls, testing, and final production-ready delivery.

[Normal] 8. Technical Architecture Summary
[Normal] To ensure scalability, security, and maintainability, the application will follow a layered technical architecture as outlined below:
[Normal] Application Layer (Android Frontend)
[Normal] Native Android UI with responsive layouts for all screen sizes
[Normal] Modular UI components for easy future enhancements
[Normal] Secure session handling and OTP-based authentication flows
[Normal] Business Logic Layer
[Normal] Centralized role-based access control (RBAC)
[Normal] Separation of admin, wholesaler, and retailer permissions
[Normal] Validation logic for product management, pricing, and stock updates
[Normal] Data & Backend Layer
[Normal] Structured data models for users, roles, products, categories, pricing, and stock
[Normal] Secure API communication (if backend APIs are used)
[Normal] Designed to support future expansion (web admin, iOS app, analytics)
[Normal] Security & Reliability
[Normal] OTP-based login reduces password-related attack surface
[Normal] Role isolation prevents unauthorized feature access
[Normal] Input validation and controlled data flow
[Normal] This architecture ensures the application is future-ready, minimizes rework costs, and supports business growth without requiring a rebuild.
